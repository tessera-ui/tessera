# T0002: runtime API call outside a Tessera build context

APIs such as `remember`, `use_context`, `provide_context`, `key`, and
`RenderSlot::new` require an active Tessera build context.

Invalid:

```rust
fn helper() {
    let state = tessera_ui::remember(|| 0);
}
```

Create remembered state in a component and pass its handle to ordinary helpers:

```rust
fn read(state: tessera_ui::State<i32>) -> i32 {
    state.get()
}

#[tessera_ui::tessera]
fn counter() {
    let state = tessera_ui::remember(|| 0);
    let value = read(state);
}
```

Closure initializers and event handlers remain ordinary Rust. Writing them inside
a component does not allow runtime API calls within them. Render-slot closures
carry delayed build code; construct the slot at a valid build boundary.
