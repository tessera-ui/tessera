# T0001: component call outside a Tessera build context

Tessera components must be called from a `#[tessera]` free function or a recognized
build closure, such as a render-slot content closure.

Invalid:

```rust
#[tessera_ui::tessera]
fn child() {}

fn helper() {
    child();
}
```

If the function builds UI, make it a component:

```rust
#[tessera_ui::tessera]
fn child() {}

#[tessera_ui::tessera]
fn parent() {
    child();
}
```

Ordinary closures, callbacks, iterator closures, and local functions do not inherit
the surrounding component's build context. Move component calls into the
component body or a recognized build closure. Do not turn an event callback into
UI-building code; update state and let the component rebuild instead.
