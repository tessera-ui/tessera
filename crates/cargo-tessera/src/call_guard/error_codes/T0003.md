# T0003: unresolved Tessera-sensitive call

The checker could not resolve a call that may target a Tessera component or
runtime API. It cannot approve the call without knowing its target.

Invalid:

```rust
fn helper() {
    missing::remember(|| 0);
}
```

Check the import, dependency, selected Cargo features, and target. After resolving
the name, place a Tessera-only call inside a component or recognized build closure:

```rust
#[tessera_ui::tessera]
fn counter() {
    let state = tessera_ui::remember(|| 0);
}
```

If the intended function is an ordinary Rust helper, make its definition visible
to the checker. An unresolved call is not evidence that it is safe to execute
outside a Tessera build context.
