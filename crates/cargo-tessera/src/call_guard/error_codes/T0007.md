# T0007: a build context may emit more than one node

`layout` and `group` emit the single node of the component, slot, or build
closure that calls them. Content declared after the call is laid out by that
node, so declare it in `child`. A context must not:

- reach a second `layout` or `group` on any execution path;
- call `layout` or `group` in a loop;
- declare components or expand slots after its node outside `child`;
- emit a node from a root build closure such as `EntryPoint::new` or
  `UiTest::content`.

Invalid:

```rust
#[tessera]
fn badge_row() {
    layout(Stack).modifier(Modifier::new().size(Dp(8.0), Dp(8.0)));
    layout(Stack).modifier(Modifier::new().size(Dp(8.0), Dp(8.0)));
}
```

Emit each node from its own component, or nest it in `child` content:

```rust
#[tessera]
fn dot() {
    layout(Stack).modifier(Modifier::new().size(Dp(8.0), Dp(8.0)));
}

#[tessera]
fn badge_row() {
    layout(RowPolicy).child(|| {
        dot();
        dot();
    });
}
```
