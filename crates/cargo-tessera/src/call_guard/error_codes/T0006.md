# T0006: model state created outside a model initializer

`State::new` creates state owned by the model being initialized. It is valid
only in a model initializer:

- `init` in an `impl ModelInit` for a model type;
- a closure passed directly to `Model::new_with` or `ModelStore::model`.

Helpers called from an initializer are ordinary code and cannot call
`State::new`.

Invalid:

```rust
#[tessera]
fn counter() {
    let count = State::new(0);
}
```

Use `remember` for state owned by the component, or declare the state as a
field of a model type and create it in its `init`:

```rust
struct CounterModel {
    count: State<u32>,
}

impl ModelInit for CounterModel {
    fn init() -> Self {
        Self { count: State::new(0) }
    }
}
```
