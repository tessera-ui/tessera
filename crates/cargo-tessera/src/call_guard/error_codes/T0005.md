# T0005: private Tessera macro-support item outside generated code

The `__private` module of `tessera_ui` exists only for code
generated by official Tessera macros such as `#[tessera]`, `#[shard]`, and
`#[entry]`. Its contents can change in any release. Naming one of its items
through a direct path, an import, an alias, or a re-export is rejected; only the
defining crate and official macro expansions may use them.

Invalid:

```rust
use tessera_ui::__private::current_instance_key;

fn instance() -> u64 {
    current_instance_key()
}
```

Use the public Tessera API that provides the needed behavior. If a component
needs runtime plumbing that has no public equivalent, declare it with an official
macro instead of calling the generated-code support directly.
