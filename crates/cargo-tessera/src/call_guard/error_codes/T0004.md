# T0004: invalid Tessera lint configuration

Use `#[tessera_ui::lint(level(tessera::redundant_render_slot))]` on an item or
inline module. Supported source levels are `allow`, `warn`, `deny`, and `forbid`.
`tessera::all` selects all Tessera lints; `warnings` selects default warnings.
The `tessera::` prefix is optional inside this attribute.

Use a recognized lint name and parenthesized level groups. An inner scope cannot
lower an effective `forbid` level. Command-line `--force-warn` remains fixed, and
`--cap-lints` limits other lint levels. Lint configuration does not suppress
Tessera call errors.
