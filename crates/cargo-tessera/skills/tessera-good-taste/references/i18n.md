# Localization

- Configure `[i18n]` in `tessera-config.toml`, keep feature catalogs under `locales/<language>/`, and use the scaffold's `tessera_build::build()` entry.
- Register the generated catalog with `EntryPoint::package(res::i18n())`. The entry owns the language state.
- Resolve messages near their output with `res::I18N.text` and `res::I18N.format`. Use stable semantic IDs and named arguments; express complete sentences, plurals, and grammatical choices in Fluent.
- Switch language through `I18n::current().set_locale`. Keep route keys, selection identities, and user-entered content independent of translated text.
- Translate visible copy and accessibility labels together. Keep catalogs complete and choose a fallback. Preserve product names, color and typography role names, API identifiers, and code samples.
- Override built-in component messages through their `md3-...` IDs in application catalogs.
